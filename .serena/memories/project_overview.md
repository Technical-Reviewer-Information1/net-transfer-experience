# Project Overview: Net Transfer Experience

## Purpose
This is a Streamlit web application that simulates and visualizes network transfer speeds. It provides users with an interactive experience to understand how different network conditions affect file transfer times.

## Tech Stack
- **Framework**: Streamlit (web app framework)
- **Visualization**: Plotly (interactive charts and graphs)
- **Data Processing**: Pandas, NumPy
- **Runtime**: Python 3.11
- **Development Environment**: VS Code Dev Container

## Key Features
- Network transfer speed simulation
- Interactive file size selection
- Network condition simulation
- Real-time progress visualization
- Transfer history tracking
- Speed comparison charts

## Application Structure
- **Main File**: `app.py` - Contains the entire Streamlit application
- **Dependencies**: Listed in `requirements.txt`
- **Development**: Configured for Dev Container with automatic Streamlit server startup
