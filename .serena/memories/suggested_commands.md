# Suggested Commands

## Development Commands
- **Run the application**: `streamlit run app.py`
- **Run with specific configuration**: `streamlit run app.py --server.enableCORS false --server.enableXsrfProtection false`
- **Install dependencies**: `pip install -r requirements.txt`

## System Commands (Linux)
- **List files**: `ls -la`
- **Change directory**: `cd <directory>`
- **Search for patterns**: `grep -r "pattern" .`
- **Find files**: `find . -name "*.py"`
- **Git operations**: `git status`, `git add .`, `git commit -m "message"`

## Port Information
- **Default Streamlit port**: 8501
- **Application URL**: `http://localhost:8501`

## Docker/Container Commands
- **Dev Container**: Automatically starts Streamlit server on port 8501
- **Manual container build**: Use the devcontainer.json configuration
